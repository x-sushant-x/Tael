#### Tael - A `tail` alternative.
An alternative to the `tail` command is being built to compare the performance of C and Go.

##### Supported Commands:
* `tael -r <file_name>` - Displays last 10 lines
* `tael -r<lines><file_name>` - Displays given lines.
* `tael -f <file_name>` - Display new changes continuously in file. (In Progress)
